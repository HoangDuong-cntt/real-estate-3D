# Draco Decoder Directory

Place Google Draco decoders here (`draco_decoder.js`, `draco_decoder.wasm`, `draco_wasm_wrapper.js`) to support compressed glTF/GLB files:
You can copy them from `node_modules/three/examples/jsm/libs/draco/gltf/` into this directory.

The frontend `ModelLoader.js` is pre-configured to look for Draco decoders at `/draco/`.
